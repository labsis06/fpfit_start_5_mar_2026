Oppure carica il file .p01

Parametri FPFIT

Legenda parametri FPFIT

  • ttl: Titolo del run (solo descrittivo). Tipo string
  • for: Formato input (1 = Hypo71). Tipo int
  • mag: Magnitudo (non usata). Tipo float. Valori ammessi: mag >= 0
  • obs: Numero minimo di stazioni richieste. Tipo int. Valori ammessi: obs >= 4 (consigliato >= 6)
  • dis: Distanza massima delle stazioni dall'epicentro (metri). Tipo float. Valori ammessi: dis > 0
  • res: Errore massimo accettato. Tipo float. Valori ammessi: res > 0; 1 → molto restrittivo - 100 → permissivo
  • ain: Intervallo angolo di uscita. Tipo float. Valori ammessi: 0 ≤ ain ≤ 180; Esempio: ain 0. 180.
  • amp: Uso ampiezze (0 = no). Tipo int. Valori ammessi: 0 = no; 1 = sì; normalmente: 0
  • bst: Bootstrap (0 = disattivato). Tipo int. Valori ammessi: 0 = off; 1 = on; normalmente: 0
  • fin: Stampa soluzione finale. Tipo int. Valori ammessi: 0 / 1; deve essere 1
  • rep: Stampa report. Tipo int. Valori ammessi: 0 / 1; deve essere 1
  • cmp: Confronto soluzioni. Tipo int. Valori ammessi: 0 / 1; normalmente: 0
  • hdr: Parametri interni di qualità. Tipo float. Valori ammessi: hdr > 0; modifica sconsigliata
  • mcr: Controllo errori. Tipo float. Valori ammessi: mcr > 0; modifica sconsigliata
  • dir: Ricerca strike (orientazione faglia). dir min max step_coarse step_fine. Valori ammessi: 0 ≤ min < max ≤ 360; step > 0; Esempio: dir 0.00 360.0 20.00 5.000
  • dip: Ricerca inclinazione faglia. dip min max step_coarse step_fine. Valori ammessi: 0 ≤ min < max ≤ 90; step > 0; Esempio: dip 0.00 90.00 20.00 5.000
  • rak: Ricerca direzione movimento faglia. rak min max step_coarse step_fine. Valori ammessi: -180 ≤ min < max ≤ 180; step > 0; Esempio: rak -180.0 180.0 20.00 10.00

Questi parametri vengono usati per costruire h71.inp prima di lanciare FPFIT. Le modifiche vengono salvate con backup automatico.
