Oppure carica il file .p01

Parametri FPFIT

Legenda parametri FPFIT

  • ttl: Titolo del run (solo descrittivo)
  • for: Formato input (1 = Hypo71)
  • mag: Magnitudo (non usata)
  • obs: Numero minimo di stazioni richieste
  • dis: Distanza massima (metri)
  • res: Errore massimo accettato
  • ain: Intervallo angolo di uscita
  • amp: Uso ampiezze (0 = no)
  • bst: Bootstrap (0 = disattivato)
  • fin: Stampa soluzione finale
  • rep: Stampa report
  • cmp: Confronto soluzioni
  • hdr: Parametri interni di qualità
  • mcr: Controllo errori
  • dir: Ricerca strike (orientazione faglia)
  • dip: Ricerca inclinazione faglia
  • rak: Direzione movimento sulla faglia

Questi parametri vengono usati per costruire h71.inp prima di lanciare FPFIT. Le modifiche vengono salvate con backup automatico.
